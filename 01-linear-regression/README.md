# 第一课：线性回归预测房价

这个项目是从机器学习走向深度学习的第一步：用房屋面积预测价格。数据是**虚构的教学数据**，预测结果不能用于真实购房或投资决策。项目只需要 Python 3，不需要安装第三方库，也不需要联网下载数据。

## 运行

在本目录打开终端：

```bash
python house_price.py
python house_price.py --area 85
```

如果 Windows 上 `python` 命令不可用，可以尝试 `py house_price.py --area 85`。面积单位是平方米，价格单位是万元。

## 理解代码

1. 每条数据是 `(面积, 房价)`。程序固定随机种子后，将 20 条数据分成 16 条训练数据和 4 条测试数据。
2. 模型是一条直线：`预测房价 = 斜率 × 面积 + 截距`。斜率表示面积增加 1 平方米时，模型预测的价格变化；截距是面积为 0 时的数学结果，不一定有实际意义。
3. `fit` 使用最小二乘法计算训练集上的斜率和截距，使训练样本预测误差的平方和最小。
4. 程序在未参与训练的测试集上计算平均绝对误差（MAE）：每个预测值与真实值的差取绝对值，再求平均。越小通常越好，但这个极小的虚构测试集不能证明模型在真实市场上有效。
5. 用 `--area` 输入一个面积，查看模型给出的预测。

## 动手练习

- 把预测面积改为 70、100、130，观察价格变化。
- 修改一条训练数据的价格，重新运行并观察斜率和误差如何变化。随机划分后，修改的数据可能落在测试集，注意比较输出。
- 尝试添加更多样本，再想一想：地段、房龄等因素为什么也会影响价格？只用面积有什么局限？
