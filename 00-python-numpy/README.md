## 从一个样本扩展到一批

`X = [[1, 2], [2, 1], [3, 4]]` 是三个样本、两个特征；权重为 `[2, -1]`，偏置为 `3`。第一个预测是 `1×2 + 2×(-1) + 3 = 3`。完整预测为 `[3, 6, 5]`，标签为 `[4, 5, 6]`，所以 MAE 为 `(1+1+1)/3 = 1`，单位与标签相同。

| 对象 | 形状 | 含义 |
| --- | --- | --- |
| `X` | `(3, 2)`，一般为 `(n, d)` | 每行一个样本 |
| `weights` | `(2,)`，一般为 `(d,)` | 每列一个权重 |
| `bias` | 标量 | 每个样本共用的截距 |
| `X @ weights + bias` | `(3,)`，一般为 `(n,)` | 每个样本一个预测 |
| `y` | `(3,)` | 标签与预测一一对应 |

`@` 做矩阵乘法；`+ bias` 把标量广播到每个预测。`X.mean(axis=0)` 得到每列均值，`axis=1` 得到每行均值；不指定 `axis` 会汇总所有元素。`X[:, 0]` 取第一列，`X[:2]` 取前两个样本。

## 最常见的坑：能运行，却算错

`y[:, None]` 把 `(n,)` 变成 `(n, 1)`。它减去 `(n,)` 的预测会广播成 `(n, n)`，比较了所有标签与所有预测，而不是逐样本误差。脚本故意展示这个错误形状，但 `mae_numpy` 会拒绝这种输入并抛出 `ValueError`。不要为了通过异常而盲目加 `reshape`：先确认每个轴的含义。

平方误差为 `(prediction - target)²`，对 prediction 的导数是 `2×(prediction - target)`；预测偏高时导数为正，沿负梯度更新才能把它降下来。MSE 是平方误差的均值，梯度还要除以样本数。MAE 使用绝对值，是另一个目标。

## 自己完成的练习

1. 先手算第二个预测，再比较两个实现；改一个权重，解释每个预测怎样变化。
2. 打印 `X.mean(axis=0)`、`X.var(axis=0)`、`X @ weights` 的值和形状。
3. 故意传入长度错误的权重，沿 traceback 找到文件名、行号、异常类型；修复输入而不是删除检查。
4. 用很小的差分估计平方误差导数，和 `2×(prediction-target)` 对照。

通过标准：能解释 `(n,d) @ (d,) -> (n,)` 和广播陷阱，能手算预测与 MAE。此处没有拟合模型、训练/测试划分或泛化结论；下一课才用数据估计参数。
