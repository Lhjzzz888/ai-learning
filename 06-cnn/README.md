# 06｜CNN：用相同实验条件检验结构

[返回学习目录](../README.md) · [上一课 MLP](../05-pytorch-mlp/README.md) · [阶段要求](../docs/ROADMAP.md#06用-cnn-验证结构对图像任务的影响)

这一课使用同一个离线 `load_digits` 数据集，同时重新训练 MLP 和 CNN。两者使用相同训练／验证／测试样本、像素除以 16 的规则、优化器、轮数、批次大小和指标。先安装根目录说明中的神经网络依赖，在仓库根目录运行：

```powershell
python 06-cnn/train.py --epochs 20
python 06-cnn/train.py --epochs 3 --output-dir artifacts/06-smoke
```

默认 CPU、单线程、种子 42。可以使用 `--batch-size 64 --lr 0.01 --weight-decay 0 --threads 1` 明确写出公共预算。默认 MLP 宽度为 64；CNN 通道起点为 8、隐藏宽度为 32。这里固定两种配置作比较，没有测试集搜索。相同 epoch 表示相同数据遍历次数，不代表相同计算量；因此同时报告参数量和实测耗时。

## 从像素到 logits

MLP 将图像展平成 64 维向量；CNN 的卷积核在局部区域共享参数。CNN 的路径如下，`N` 为批次大小：

| 层 | 输出形状 | 作用 |
| --- | --- | --- |
| 输入 | `[N, 1, 8, 8]` | 灰度图，像素固定除以 16 |
| 3×3 Conv，padding=1，stride=1 | `[N, 8, 8, 8]` | 提取局部特征 |
| ReLU | `[N, 8, 8, 8]` | 非线性 |
| 2×2 MaxPool，stride=2 | `[N, 8, 4, 4]` | 只缩小一次空间尺寸 |
| 3×3 Conv，padding=1，stride=1 | `[N, 16, 4, 4]` | 组合局部特征 |
| ReLU、Flatten | `[N, 256]` | 保留小图的空间信息后展平 |
| Linear、ReLU | `[N, 32]` | 分类隐藏层 |
| Linear | `[N, 10]` | 原始 logits，直接送入交叉熵 |

脚本保存每层的实测 `shape_trace`，包括批次大小为 1 的输入。对 8×8 图像反复池化可能过早丢失细节，所以这里只池化一次。训练、评估与检查点实现复用 `learning/vision.py`，避免两个网络各有一套不一致的指标算法。

## 比较规则和产物

先分别按验证交叉熵选出两种网络的最佳轮次，然后只根据验证损失选出候选模型。两种配置与检查点全部锁定后，才统一报告各自的最终测试结果。测试结果用于交代最终表现，不参与赢家选择。不要因为看到测试分数就返回修改网络后继续在同一测试集比较。

默认输出 `artifacts/06-cnn/`：

- `comparison.json`：两种模型的配置、公共训练预算、参数量、最佳轮次、验证损失／准确率、训练耗时、最终测试表现及形状。
- `mlp/`、`cnn/` 中各有 `best.pt`、`curves.csv`、`curves.svg`。
- 每个模型的 `errors.json`、`errors.svg`：按固定测试顺序选前 5 个错分；不足 5 个时记录全部，同时报告总错误数。JSON 保留原始样本 ID、标签、置信度与 8×8 原始像素。

耗时包括每轮训练、验证和最佳检查点写入，不含首次数据读取、模型建立及最终测试；短任务受机器负载影响明显。参数量、验证指标和时间一起看，不能预设 CNN 必须优于 MLP。本课不提供虚构分数，实际数值以运行后的 JSON 为准。

重载 CNN 做同一套验证样本预测，复用上一课的加载入口即可：

```powershell
python 05-pytorch-mlp/train.py --checkpoint artifacts/06-cnn/cnn/best.pt --predict-index 0
```

保存文件包含配置和参数，以 `weights_only=True` 安全方式读取；同一环境中保存和重载的预测精确一致检查结果写在报告里。这些推理检查点未包含完整训练状态，不支持精确断点续训。

## 如何写错误分析

打开两份 `errors.svg`，逐个对应 JSON 中的标签与原始 ID。记录笔画是否模糊、哪对数字容易混淆、模型是否过度自信。两个模型各取自己的前 5 个错误，因此示例不一定是同一组样本；不要仅凭这几张图得出整体优劣结论。最终测试错误可用于解释局限；要基于错误开发新版本，应另建验证实验和新的独立测试评估。

扩展练习一次只选一项，在训练／验证阶段完成比较：尝试 `--weight-decay 0.001`；加入 Dropout 后检查 `train/eval` 行为；或写基于验证损失的早停。本课固定运行预算后选最佳检查点，没有实现提前停止，也没有默认加入 Dropout。权重衰减、Dropout、早停都不能保证提高效果。

数据来源、划分边界和固定缩放规则与上一课相同。8×8 的教学结论不能直接推广到更大图像；以后使用需下载的 Fashion-MNIST 时，两种网络应重新建立共同基线，不能和这里的分数直接比较。
