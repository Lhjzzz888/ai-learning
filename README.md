# AI 学习之路：从线性回归到自己训练小型模型

**目标：理解模型怎样从数据中学习，独立完成数据准备、训练、评估和推理，最终从随机初始化训练一个小型字符级 Transformer。**

学习顺序按“先做出结果 → 理解原理 → 对照实现 → 分析失败”推进。数学按项目需要补充；每一阶段用实践成果判断是否可以继续。

> **材料状态说明**：目前仓库只有 [第一课：线性回归](01-linear-regression/README.md) 提供可运行代码。下表其余模块是学习计划，详细任务见 [阶段指南](docs/ROADMAP.md)。代码已提供不代表学习者已经掌握，个人进度请用 [学习记录模板](docs/LEARNING_LOG_TEMPLATE.md) 记录。

## 必学主线

模块 00 是基础检查；模块 01–09 按顺序推进。每个模块的详细先修、练习和验收都在 [阶段指南](docs/ROADMAP.md)。

| --- | --- | --- | --- |
| 00 | Python、NumPy 与必要数学 | 能用函数处理数据、解释数组形状，计算均值和简单导数 | 计划中 |
| 01 | 一元线性回归 | 运行房价示例，解释最小二乘解和测试 MAE，计算常数预测基线 | [代码已提供](01-linear-regression/README.md)；基线是动手练习 |
| 02 | 梯度下降、多元回归与正则化 | NumPy 梯度下降实验；对比线性回归、Ridge 和 Lasso | 计划中 |
| 03 | 逻辑回归与分类评估 | 二分类实验；混淆矩阵、精确率、召回率与阈值比较 | 计划中 |
| 04 | 决策树、随机森林与梯度提升 | 在同一数据划分上比较简单基线、线性模型和树模型 | 计划中 |
| 05 | PyTorch 与多层感知机（MLP） | 自己写训练循环，完成小批次过拟合、验证与保存加载 | 计划中 |

这里的“从零训练”指**不加载预训练权重**，可以使用 PyTorch 张量、自动求导和优化器。手写 NumPy 回归帮助理解优化；不用先把每一种算法和底层算子都手写一遍。

## 每个项目都遵守的学习方法

1. **先固定问题和基线**：回归先做常数预测，分类先做多数类预测，语言建模先做 bigram。
2. **先划分数据再拟合处理流程**：标准化、缺失值填充、特征选择与词表只能从训练数据学习；按任务选择随机、分组或时间划分。
3. **先确认流程能学，再扩大规模**：检查数据与标签、数组形状、损失；神经网络先在极小训练子集上过拟合。
4. **用验证集做选择**：改学习率、网络大小或训练轮数时记录结果；最终方案锁定后再用测试集评估。
5. **记录证据**：每个项目留下一条运行命令、一份结果表、一张有用的图或样例，以及一次失败分析。模板见 [学习记录](docs/LEARNING_LOG_TEMPLATE.md)。

第一课只有 20 条虚构数据，采用训练／测试划分演示基本流程；进入需要调参的模块后，再使用独立验证集或训练部分内的交叉验证。

## 选修：有需要时再展开

这些内容保留在知识地图里，可在完成相应基础后选择，不阻塞小型 Transformer 主线。

| 方向 | 适合什么时候学 | 建议练习 |
| --- | --- | --- |
| K 近邻、朴素贝叶斯、SVM | 模块 03 后，想比较不同分类方法 | 在同一分类数据上比较；距离与间隔模型注意标准化 |
| K-means、PCA | 模块 04 后，想理解聚类和降维 | 聚类可视化；PCA 只在训练数据拟合，检查降维前后表现 |
| XGBoost 或 LightGBM | 模块 04 后，想深入表格数据 | 先用 scikit-learn 的梯度提升完成比较，再选择一种扩展库 |
| RNN、LSTM、GRU | 模块 07 后，想理解循环状态与序列建模 | 选一种循环模型，与 bigram 比较；无需把三种都实现完才学注意力 |
| 自编码器、VAE、扩散模型 | 掌握模块 05–06 后，偏好表示学习或图像生成 | 先做小型自编码器，再选择一种生成模型 |
| 预训练模型与参数高效微调 | 模块 08 后，想对比从零训练与迁移学习 | 在独立验证集上比较微调前后任务指标，记录显存和时间 |
| RAG 与 Agent | 完成基础训练闭环后，另做应用方向项目 | 从可评估的检索问答开始，再考虑工具调用 |

## 接下来一周怎么做

先按每周 **6–8 小时**试跑，这是建议节奏；基础不足时延长模块 00，按验收推进。一次安排约 45–90 分钟，剩余时间用于排错与复盘。

| 次数 | 行动 | 完成标志 |
| --- | --- | --- |
| 第 1 次 | 运行第一课，读 `fit` 和数据划分部分 | 能指出训练数据、测试数据、参数和预测的区别 |
| 第 2 次 | 手算一个预测值与一个样本的绝对误差 | 结果与程序对应，能解释 MAE 的单位 |
| 第 3 次 | 用训练标签的均值做常数预测，与回归比较测试 MAE | 留下一张两行结果表；解释为什么均值只用训练标签计算 |
| 第 4 次 | 检查 Python 函数、列表及 NumPy 形状的掌握情况 | 能独立写出预测与 MAE 函数；不会的内容回到模块 00 |
| 第 5 次 | 写第一份学习记录，开始模块 02 的梯度下降练习 | 能说出当前 `fit` 是闭式解，梯度下降将通过迭代更新参数 |

如果第一课已经熟练，直接做验收后进入模块 02。不要把“看完课程”当作完成标准。
