# AI 学习之路

从线性回归出发，依次掌握机器学习和深度学习的核心模型，最终从随机初始化开始训练自己的小型 AI 模型。目录是学习计划；只有标注“已完成”的项目已经提供代码。

### 第三阶段：从零训练自己的 AI

1. **明确任务**：先选一个可衡量的小问题，例如中文字符级文本生成，定义数据、评估方法和基线。
2. **准备数据**：收集有权使用的数据，清洗和去重；先划分训练、验证、测试集，再建立词表或分词器，避免数据泄漏。
3. **实现小模型**：从随机权重初始化字符级语言模型；先用简单模型验证流程，再实现小型 Transformer，理解输入、预测下一个 token 和损失。
4. **训练和排错**：配置批次、优化器、学习率、随机种子及检查点；先让模型在一小批数据上过拟合，确认流程正确，再进行完整训练。
5. **评估和改进**：观察验证集损失与困惑度，检查生成样本和失败案例；只用测试集做最终评估，记录数据、参数和结果。
6. **使用与部署**：保存模型和分词器，编写推理程序，提供简单的命令行或应用接口，记录模型的限制。
7. **扩展**：尝试更大或更高质量的数据、不同模型和硬件；另外学习使用预训练模型进行微调，并与从零训练对比。

从零训练小模型可以帮助理解完整流程；训练具有通用能力的大语言模型通常需要大量数据、算力和工程投入。微调预训练模型是另一条实践路径，不等同于从随机权重训练。
