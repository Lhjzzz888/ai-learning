# 阶段指南：基础、实验与训练闭环

[返回学习目录](../README.md) · [学习记录模板](LEARNING_LOG_TEMPLATE.md)

本指南把学习路线拆成可检查的任务。除第一课外，下列项目都是**待实现的练习规格**，不是仓库已经提供的课程或程序。目标是从随机权重训练小型模型；教材用于解释和对照，最终要能说明自己的代码与结果。

## 如何安排进度

- 先做每个模块的验收；已经会的部分可以跳过重复练习。
- 每次学习围绕一个小问题：读必要原理、写一个实验、记录一个结论。每次只改一个主要因素，方便解释结果。
- 每个模块以能独立复现的成果收尾。没有达到验收，就缩小问题并排错，不急着增加模型种类。
- 先试行首页的每周 6–8 小时节奏，连续两周记录实际耗时后再估计剩余进度；没有统一的“几周学会 AI”期限。
- 数学补到能解释本次实验即可：回归补均值、向量和导数；分类补概率、对数与交叉熵；神经网络补链式法则；注意力补矩阵乘法和 softmax。

## 00｜够用的 Python、NumPy 与数学

**进入条件**：会打开终端并运行 Python 文件。完全没有编程经验时，先练变量、条件、循环、函数与列表，再读第一课。

**要学什么**：函数、模块、文件读写和报错定位；NumPy 数组、索引、广播、`shape` 与 `axis`；向量点积、均值、方差、一次函数和导数。接触第三方库时，学习虚拟环境与依赖记录。

**动手产物**：用 Python 写预测和 MAE 函数，再用 NumPy 改写；为一组样本打印 `X`、`y`、参数和预测值的形状。

**通过标准**：能解释 `(n, d) @ (d,) -> (n,)`；知道 `(n,)` 与 `(n, 1)` 的运算可能触发意外广播；能看懂异常中的文件名和行号；能解释平方误差对预测值的导数。

**资源**：[Python 中文教程](https://docs.python.org/zh-cn/3/tutorial/)适合已有基本编程概念后查阅；[NumPy 入门](https://numpy.org/doc/stable/user/absolute_beginners.html)重点看数组、形状和基本运算；数学配合《动手学深度学习》第 2 章。

## 01｜用现有线性回归课建立完整概念

**进入条件**：能读懂函数、列表和简单算术。

**要学什么**：特征、标签、参数、预测、训练／测试划分；最小二乘解与 MAE 的区别。现有 `fit` 直接计算斜率和截距，**没有迭代训练或反向传播**；它优化平方误差，程序用 MAE 报告测试表现。

**动手产物**：运行 [现有课程](../01-linear-regression/README.md)；计算“始终预测训练标签均值”的常数基线；在完全相同的测试样本上比较基线和线性回归的 MAE。这里用均值连接最小二乘思想；若专门寻找训练集上 MAE 最小的常数，可以再比较训练标签的中位数。

**通过标准**：能手算一个预测和绝对误差，解释斜率、截距与 MAE 单位；知道 4 个虚构测试样本不能证明实际效果；留下原始结果，不根据这个测试集反复改模型。

**完成后**：带着“如果不能直接求出最优参数怎么办”进入梯度下降。

## 02｜从闭式解走向梯度下降、多特征和正则化

**进入条件**：完成模块 00–01，能解释点积和简单导数。

**要学什么**：MSE、梯度、学习率和迭代；多元线性回归；欠拟合、过拟合；L2（Ridge）与 L1（Lasso）正则化。先写一元 NumPy 梯度下降，再扩展到多个特征。

**动手产物**：

1. 用相同的一元训练数据，对照闭式解和梯度下降的最终预测、损失曲线；改变学习率，观察不收敛、收敛慢和正常下降。
2. 生成固定随机种子的多特征回归数据，加入噪声或无关特征；记录生成规则，避免把虚构结果解释成真实业务结论。
3. 先留出测试集，再在训练部分内用交叉验证比较线性回归、Ridge 和 Lasso；标准化放进 `Pipeline`，使每个折的处理只从该折训练数据学习。

**通过标准**：能解释学习率过大为何可能发散；说明正则化强度如何选择；比较的是同一数据和指标；能解释正则化并不保证每次得分更好。

**资源**：[scikit-learn 入门](https://scikit-learn.org/stable/getting_started.html)、[预处理与数据泄漏](https://scikit-learn.org/stable/common_pitfalls.html)；《动手学深度学习》的线性回归与梯度下降章节。

## 03｜逻辑回归、概率与分类评估

**进入条件**：完成模块 02，理解训练、验证和最终测试的分工。

**要学什么**：sigmoid、二元交叉熵、类别概率、阈值、混淆矩阵、precision、recall、F1；理解多分类中的 softmax 与交叉熵，为 MLP 做准备。

**动手产物**：用固定随机种子的 `make_classification` 生成二分类数据，设置类别不均衡；对比多数类基线和逻辑回归。在验证数据上比较至少两个阈值，说明漏报与误报哪个更重要，并据此选主指标。

**通过标准**：能从混淆矩阵计算 precision 和 recall；解释为什么不只看 accuracy；阈值在验证集选择，不能按测试结果修改。随机划分的独立分类样本可使用分层抽样；有时间或实体关联时，应改用相应划分策略。

## 04｜用树模型完成第一次机器学习比较实验

**进入条件**：完成回归或分类的评估流程。

**要学什么**：决策树深度、随机森林、bagging 与 boosting 的区别；交叉验证与特征重要性的局限。梯度提升先用 scikit-learn 实现即可。

**动手产物**：沿用模块 02 或 03 的一个任务，对比常数／多数类基线、线性模型、决策树、随机森林和一种梯度提升模型。固定数据划分、主指标与小规模搜索预算，报告交叉验证均值及波动，选定方案后进行最终测试。

**通过标准**：能解释哪种模型在什么条件下更合适；至少分析几个错误或大残差样本；知道特征重要性不代表因果关系；结果不如简单模型时，能够如实记录并检查原因。

**阶段里程碑 A**：独立完成一份表格数据实验报告，包含问题、数据、基线、划分、指标、模型比较和局限。到这里再进入深度学习，不必先学完所有传统算法。

## 05｜把神经网络原理与 PyTorch 训练循环一起学

**进入条件**：理解梯度下降、数组形状、训练与验证。

**要学什么**：线性层、激活函数、MLP、计算图、链式法则；张量、自动求导、Dataset／DataLoader、损失、优化器与设备。先手推一个小例子的梯度，再用自动求导验证，不要求先手写完整框架。

**动手产物**：用 scikit-learn 自带的 `load_digits` 小型数字图像数据训练 MLP；先划分，再处理；只用训练数据确定需学习的变换。写出并解释以下流程：

```text
训练：切到 train 模式 → 取批次 → 梯度清零 → 前向计算 → 损失 → 反向传播 → 更新参数
验证：切到 eval 模式 → 关闭梯度计算 → 前向计算 → 按样本数汇总指标
保存：按验证指标选择检查点 → 保存参数与模型配置 → 加载后比较预测
```

**通过标准**：先在很小的训练子集上得到明显下降、接近零的训练损失，确认流程能学；再画完整训练与验证曲线。能解释为什么要清零梯度、为什么 `eval()` 不等于关闭梯度，以及类别交叉熵通常接收原始 logits。保存、重载后，在评估模式下预测应在数值容差内一致。

**资源**：[PyTorch Learn the Basics](https://docs.pytorch.org/tutorials/beginner/basics/intro.html)，按张量、数据、建模、自动求导、优化、保存加载的顺序练习。

## 06｜用 CNN 验证结构对图像任务的影响

**进入条件**：能独立写模块 05 的训练与验证循环。

**要学什么**：卷积、通道、步幅、填充、池化与参数量；Dropout、权重衰减和早停的基本作用。

**动手产物**：先在模块 05 的 8×8 灰度图上做小 CNN，逐层检查形状，避免过度池化；与 MLP 使用相同划分和指标。若希望做更完整的图像练习，再选择 Fashion-MNIST，并为两种模型重新建立共同基线；该数据需要下载。

**通过标准**：能画出输入到输出的形状变化；比较参数量、验证表现与训练时间；整理至少 5 个错分案例，样本不足时记录全部。结论由实验支持，不预设 CNN 必须赢。

**阶段里程碑 B**：交出可以保存、重载并预测新样本的图像分类器，以及一份错误分析。

## 07｜先学文本数据，再训练字符级基线

**进入条件**：能完成训练循环，理解分类交叉熵和概率。

**要学什么**：字符与 token、词表、embedding、上下文、下一个 token 预测、负对数似然与困惑度；bigram 只根据前一个 token 预测下一个 token。

**动手产物**：

1. 选择自写或许可明确的中文文本，记录来源、许可和清洗规则。先去重、识别同源文档，再按文档或来源组划分训练／验证／测试，最后在各部分内部切序列窗口。不要先切出重叠窗口再随机划分。
2. 只有一篇长文本时，可按连续区段划分且不跨边界取窗口，必要时在边界留出至少一个上下文长度的间隔；记录同篇文本评估的局限。
3. 只用训练文本建立字符词表，预留未知字符标记，记录验证／测试的未知字符比例；不通过读取测试字符来扩充词表，也不静默丢弃未知字符。
4. 先检查输入 `[c0, c1, c2]` 对应标签 `[c1, c2, c3]`。训练一个可学习的 bigram 概率表，再实现自回归采样。

**通过标准**：能打印并解释一批输入、标签和预测分布；在固定词表与评估规则下报告验证集每 token 平均交叉熵；知道使用自然对数时 `PPL = exp(平均交叉熵)`，变长序列需要按有效 token 数汇总。

**完成后**：固定数据、词表和评估方式，作为模块 08 的比较基准。

## 08｜注意力与自己的小型 Transformer

**进入条件**：完成模块 07；能解释矩阵乘法、softmax 和自回归生成。

**要学什么**：Q／K／V、缩放点积注意力、因果掩码、多头注意力、位置表示、残差连接、LayerNorm、前馈网络；理解 decoder-only 模型怎样预测下一个 token。

**动手产物**：

1. 用几个 token 手算或打印一次注意力矩阵。检查因果掩码，让位置 `t` 无法读取未来 token；在评估模式下改变未来输入，前面位置的输出应保持一致（允许浮点误差）。
2. 用 PyTorch 张量操作写一个最小自注意力块，组成小型 decoder-only 模型。从随机权重开始，沿用模块 07 的数据和词表。
3. 先跑一个批次，再做极小训练子集过拟合。检查输入、标签错位、注意力掩码、损失下降和生成循环，再扩大训练。
4. 用相同验证数据、词表及 token 计分方式比较 bigram 和 Transformer；记录有效 token 数、参数量、上下文长度、训练步数和耗时。
5. 只选择一个改动做对照，例如上下文长度或模型宽度。保存验证指标最好的检查点；选定方案后统一进行最终测试。

**建议起点**：2 层、隐藏维度 64、4 个注意力头、上下文长度 64、批次大小 8；这是便于试跑的教学配置，不是性能或耗时承诺。每头维度为 16，隐藏维度必须能被头数整除。参数量还会受词表大小影响。

**通过标准**：验证损失相对初始模型有明确改善；能解释与 bigram 的差距，未超过时检查数据量、实现和训练预算并记录结论；展示固定提示下的样本和失败案例。能说明温度采样改变生成分布，但不等于提高模型本身的评估得分。

**注意比较条件**：不同词表、分词器或计分规则下的困惑度不能直接横比；测试集分数不再用于挑模型。小数据训练的生成器可能重复、记忆片段或不连贯，这些都应进入报告。

## 09｜把“训练过”变成“可以复现和使用”

**进入条件**：已经确定模型、数据版本和检查点选择规则。

**最终交付清单**：

- [ ] 数据说明：来源、许可、清洗、去重、划分方法、样本或 token 数，以及未知字符比例。
- [ ] 训练入口：一条明确的启动命令、配置文件、环境与依赖版本；说明 CPU／GPU 设置。
- [ ] 模型产物：参数、模型配置、词表及特殊 token；若要恢复训练，还需优化器、步数和相关随机状态等。
- [ ] 实验记录：基线、训练／验证曲线、选定方案、最终测试结果、耗时和硬件信息。
- [ ] 推理入口：加载已有检查点，给定提示和随机种子生成文本；说明截断、未知字符和最大生成长度的处理。
- [ ] 结课报告：展示成功与失败样例，说明数据规模与能力边界，写清下一个最值得尝试的改动。

**通过标准**：换一个干净虚拟环境，能按说明加载模型并生成结果；能重新运行一次小规模训练；在相同环境和评估模式下，保存前后的预测在数值容差内一致。固定随机种子有助于复现，但不保证跨硬件、库版本完全一致。

**阶段里程碑 C**：一个可复现的小型字符级语言模型。它证明你走通了训练流程；通用对话能力仍需要另外的数据、规模和训练方案。

## 算力和环境不足时怎么缩小实验

| 情况 | 先做什么 | 仍然保留的学习目标 |
| --- | --- | --- |
| 只有 CPU | 表格数据用合成小数据；图像先用 `load_digits`；文本先跑 bigram 和极小 Transformer | 数据划分、训练循环和正确评估 |
| 训练太慢 | 先测少量训练步的耗时；缩短上下文、减少层数／宽度或数据量，再记录新的配置 | 能比较、能复现的小实验 |
| 内存或显存不足 | 减小批次和上下文，检查是否错误保留计算图；先解决流程问题再扩大模型 | 正确的梯度与验证流程 |
| 下载数据受限 | 前期使用已有虚构数据、生成数据和库内置小数据；文本用自写语料 | 离线完成最小闭环，并诚实记录数据局限 |
| 想尝试 GPU | 依据实际训练耗时与内存需求选择；按官方安装说明匹配设备，记录环境 | 用实测结果决定资源投入 |

第一课继续只用 Python 标准库。后续到用得上时再引入 NumPy、绘图工具、scikit-learn 和 PyTorch；先保持一个可复现的小环境，再逐步增加依赖。

## 后续扩展的边界

原路线中的 KNN、朴素贝叶斯、SVM、聚类／PCA、循环网络和生成模型保留为 [选修方向](../README.md)，按兴趣补充。

完成主线后，可用 [Hugging Face LLM Course](https://huggingface.co/learn/llm-course/chapter1/1) 学习预训练模型、数据与分词器，再做微调实验。预训练模型微调是在已有权重上继续学习；RAG 是引入检索资料的应用方式；它们与本路线的随机初始化训练有不同目标，记录时要分别说明。
