# 原创教学语料：十二处日常

`corpus.json` 的 24 篇中文短文由本仓库此次课程实现专门创作，无外部摘录、抓取或下载。作者是本次贡献者使用的 OpenAI Codex；贡献者将这些**新创作的语料文本及本数据说明**以 [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/) 贡献到公共领域（在法律允许范围内放弃相关权利）。这项声明仅覆盖 `data/text/` 新增内容，不改变仓库其他文件或任何第三方数据的许可。

数据不是事实资料、真实人物记录或通用中文代表样本。词句刻意重复，以便 CPU 小实验观察学习；它很容易被记忆，不能据此推断真实语言能力。

每个对象包含 `id`、`source_group`、`text`。同一场景的两篇相关短文归为一个来源组（如 `garden`）；共 12 组，不把同组文章拆到不同集合。固定随机种子 17，先按组打乱，8 组训练、2 组验证、2 组测试，然后才编码、切窗口。加载时统一 Unicode NFC、去掉两端空白，保留内部空白与标点；拒绝重复 ID、完全重复的规范化正文以及少于两个字符的文章。对近重复的识别由显式 `source_group` 完成，未实现自动语义查重。

只有训练正文决定字符词表，ID 0 为 `<unk>`。未知字符保留为 ID 0，不删除；训练程序和结果 JSON 显示每个集合的字符数、未知数与比例。字符长度按 Python Unicode 字符计，不是字节数。每篇文章第一个字符只充当上下文，后续每个字符是一个评估 target；没有跨文档拼接，也没有额外 BOS/EOS。

数据文件 SHA-256、划分种子、各集合 ID/来源组、字符数/计分 token 数及未知比例均写入检查点和 `metrics.json`。改变语料或划分种子即改变实验版本，比较前应核对这些字段。
